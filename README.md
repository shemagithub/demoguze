# demoguze

GUZE interactive clothing-rack demo (Next.js + Tailwind + Framer Motion).

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## What works

1. **Clothing rack** — swipe/arrows to browse; garments hang on the rail
2. **Hover** — side view → front view + product name
3. **Tap to inspect** — focus view with front/back flip, sizes, add to cart
4. **Cart** — right-side drawer (not a separate page)
5. **Currency** — header dropdown (EUR / USD / GBP / NGN)
6. **Pages** — About, Search, Account

## Stack

- Next.js App Router + TypeScript
- Tailwind CSS
- Framer Motion
